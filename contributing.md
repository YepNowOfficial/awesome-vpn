# Contributing to Awesome VPN

**Languages:** **English** | [简体中文](contributing.zh-CN.md)

Thank you for helping keep this VPN and networking resource list accurate, useful, and transparent.

## What belongs here

- VPN protocols, client and server software, self-hosted platforms, proxy implementations, management panels, node backends, network tools, and commercial VPN services.
- Publicly documented projects with a clear use case, verifiable official links, and a reason to be included beyond popularity.
- Carefully selected resources rather than exhaustive, auto-generated, or advertisement-only collections.

## How to suggest a project

1. Search both READMEs to avoid duplicates.
2. Open an issue or a pull request and include the canonical project URL.
3. Explain why the resource is useful, what category it belongs to, and whether it is actively maintained.
4. Add an objective one-line English entry using `- [Name](https://example.org/) - Description.`. Start descriptions with a capital letter and end them with a period.
5. Translate or update the corresponding entry in `README.zh-CN.md` so both versions remain aligned.
6. Keep each section alphabetized by project name and verify links and claims against project documentation.

## Editorial standards

- Affiliations, paid relationships, and referral/affiliate links must be disclosed. Undisclosed sponsored submissions will be rejected.
- Entries are not endorsements, rankings, security audits, or evidence that YepNow uses the listed software.
- Do not add unverifiable claims such as “the safest”, “the fastest”, or “guaranteed anonymous”.
- Prefer maintained and documented projects. Move useful but unmaintained projects to `legacy-projects.md` and update its Chinese version.
- Avoid unrelated repositories, mirrors without a reason, dead links, duplicated entries, and unsubstantiated technical claims.
- All commercial services, including YepNow, should receive the same editorial scrutiny.

## Reporting problems

Open an issue with the broken link, outdated information, security-related concern, or suggested correction. For vulnerabilities in a third-party project, contact its maintainers directly through its security-reporting channel.

## Maintainer disclosure

This repository is maintained by the team behind YepNow. The service is included with an explicit affiliation disclosure and tracked promotional links. Placement is not a claim of superiority.
