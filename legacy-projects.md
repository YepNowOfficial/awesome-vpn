# Legacy VPN and Proxy Projects

**Languages:** **English** | [简体中文](legacy-projects.zh-CN.md)

This file records historically relevant projects that are archived, discontinued, or no longer actively maintained. They are included for reference, **not as recommended production deployments**. A newer fork can remain useful even when its original upstream is inactive.

- [V2Board (original)](https://github.com/v2board/v2board) - Original proxy-service management panel. The upstream repository has limited recent activity; maintained derivatives are listed in the main README.
- [V2bX (wyx2685)](https://github.com/wyx2685/V2bX) - Multi-core node backend fork archived by its repository owner in May 2026.

For related maintained projects, see [Service Management Panels](README.md#service-management-panels) and [Node Backends](README.md#node-backends).
